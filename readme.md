# RigSmith

> Build Smarter.

RigSmith is a MERN stack application for custom PC retailers that combines inventory management, pre-built PC browsing, order management, and customer order tracking into a single platform.

The project is being developed as a portfolio project and internship assessment with a focus on scalable architecture, reusable React components, and modern UI/UX.

---

## Features

### Customer Experience

- Interactive Dashboard
- Featured Builds
- View Build Details
- Build Upgrades
- Shopping Cart
- Checkout Flow
- Order History
- Order Tracking

### Inventory Management

- Product Inventory
- Stock Monitoring
- Product Categories
- Search & Filters
- Supplier Management

### Order Management

- Customer Orders
- Order Status Tracking
- Delivery Management
- Purchase History

### Authentication

- User Accounts
- Admin Accounts
- Employee Accounts
- Role-based Access Control
